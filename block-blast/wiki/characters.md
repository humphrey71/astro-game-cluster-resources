## Block Shapes & Types in Block Blast
Unlike Tetris which only features 7 standard shapes (Tetraminos), Block Blast generates a wider variety of block shapes that appear randomly. Recognizing these shapes is key to prevent gridlock.

### 1. The Small Blocks (1x1, 1x2, 2x1)
- **1x1 Single Square**: The absolute savior block. It can fit anywhere and resolve tiny blockages.
- **1x2 or 2x1 Domino**: Tiny and versatile, easy to place.

### 2. The Line Blocks (1x3, 1x4, 1x5)
- **1x5 Giant Line**: The most dangerous block in the game. If your board is crowded, a 1x5 block can cause an instant game over. Keep slots open for it!

### 3. The L-Shapes and T-Shapes
- Standard corner shapes. Since you cannot rotate them, pay close attention to which direction their corner is pointing.

### 4. The Squares (2x2, 3x3)
- **2x2 Square**: Relatively easy.
- **3x3 Giant Square**: Requires a massive 9-grid open area. A classic game-ender if not anticipated.
